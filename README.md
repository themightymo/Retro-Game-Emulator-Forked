# Retro-Game-Emulator-Forked
A fork of https://wordpress.org/plugins/retro-game-emulator/

Administrators with upload permission can use **Upload ROMs** beside the frontend
game selector (shortcode or NES block), or on the plugin settings page. Select or
drag in uncompressed `.nes` files, then close the WordPress media uploader to
refresh the game list. Validated ROMs are saved to the site's emulator uploads
folder and become available in the game selector for visitors.
